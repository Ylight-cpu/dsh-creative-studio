# image-studio · 排版与质量规范

## 排版与版式

- 标题字号 ≈ 画面宽度的 5–8%；副标题/正文 ≈ 3–4%。一套图里只用一种强调色 + 中性色。
- 安全边距 ≥ 短边的 4%；文字永不贴边。
- 一图一意。需要三行才能说清的信息，拆成两张图。
- 文字压在复杂区域时用描边（`--stroke` + `--stroke-width`）或半透明底块（`--box '#00000099'`）。
- 九宫格定位：`tl tc tr / ml mc mr / bl bc br`。品牌签名放 `br` 或 `tr`，`--width-ratio` 保持 0.10–0.20。
- 中文/日文/韩文：显式 `--font msyh`（Windows）或系统中已有的 CJK 字体；缺字体会静默回退成方框。

## 电商主图规则（平台合规）

- 纯白背景（`--bg white`），商品占画幅比例大、留白少。
- 主图不加文字、水印、促销角标、道具（平台会拒审或降权）。
- 主图用 `pad` 而不是 `crop`：`crop` 会切掉边缘，可能裁到产品。
- 辅图/场景图可加文字与场景，用 `amazon-lifestyle` 或 `thumb-4x5`。

## 抠图质量判据

| 指标 | 含义 | 判读 |
|---|---|---|
| `transition_px` | 边缘从背景过渡到主体占几个像素 | ≈1–1.5 干净；>3 糊边/光晕，需复核或换模型 |
| `alpha_soft_ratio` | 半透明像素占比 | 毛发/纱料本就偏高；静物应很低 |
| `subject_coverage` | 主体外接框占画面比例 | 主图应接近 0.6–0.9；过低说明留白过多 |

实测参考（同一张商品图）：`u2net` transition 5.28 px / 0.15 s；`birefnet-general` 2.76 px / 5.7 s（CPU）。
毛发与玻璃类目差距更大（公开评测：毛发 71 % vs 94 %，玻璃 48 % vs 78 %），所以**别把最快档当默认**。

## 交付前自检

1. `inspect` 每个交付文件：尺寸、alpha、`subject_coverage`、`transition_px`。
2. 接触表 `sheet --labels` 一眼扫全批，检查一致性（比例、色调、文案位置）。
3. 保留原图；输出命名带差异后缀，便于回溯。
4. 当前模型看不到图时：导出接触表交给用户确认，不要替用户下"好看"的结论。

## 红线

- 不覆盖原图；不做破坏性编辑。
- 不伪造产品证据：认证标志、奖项、"100 %/最好"、假前后对比、产品没有的功能。
- 功效宣称纪律：只写材质与结构事实（plant-based / plastic-free / no dyes）；不写去除率、抗菌率、医疗或净化器式宣称，不写未持有的认证。
- 不用他人带水印的素材；缺素材就找用户要自己的拍摄或授权素材。
