# video-studio · 平台规格与节奏规范

## 平台画布

| 目标 | 画布 | 比例 | 备注 |
|---|---|---|---|
| TikTok / Reels / Shorts | 1080×1920 | 9:16 | 钩子必须在前 2 秒；文案避开顶部 ~12% 与底部 ~18%（UI 遮挡区） |
| Instagram / Facebook 信息流 | 1080×1350 或 1080×1080 | 4:5 / 1:1 | 方形在信息流里被裁切的风险最小 |
| YouTube / 官网首屏 | 1920×1080 | 16:9 | 自动播放场景留 2 秒无声开头 |
| 亚马逊/电商商品视频 | 1920×1080 | 16:9 | 不出现价格与促销文字；首帧就要能看到产品 |
| 竖版封面 | 1080×1920 | 9:16 | 用 `video-cover --scan 8` 挑最清晰帧，再交给 image-studio 加文字 |

导出默认 **H.264 + AAC + `yuv420p` + `+faststart`**，这是社交平台与浏览器期望的组合。
`--mode pad`（留白，最安全）／`--mode crop`（填满，会切边）二选一；横素材转竖版优先 pad + 上下留品牌色块。

## 节奏规范（15–40 秒短视频）

| 段落 | 时长 | 任务 |
|---|---|---|
| 钩子 | 0–2s | 一个看得见的好处或用户认得的痛点；不要 logo 开场 |
| 场景 | 2–6s | 这是给谁用的、在什么场景 |
| 证明 | 6–20s | 两到三个卖点节拍，每拍配一个画面；每 2–4 秒切一次镜 |
| 化解疑虑 | 20–30s | 一个常见反对意见（太重？难装？）用画面回答 |
| 行动 | 最后 3s | CTA + 品牌标；字幕同时上 |

字幕：每条 3–5 词、停留 ≥1.2 秒、与语音同步 ±0.3 秒；不要一句话跨两个镜头。
配乐：起始 `--music-volume 0.3`（原声 1.0），结尾 1.5 秒淡出；有人声时音乐再降 0.05–0.1。
文字贴片：屏幕文案 ≤ 8 词/行，中英混排时字号按较大字符集设定，避免中文比英文挤。

## 交付前检查（逐项）

1. `video-probe` 每个交付文件：时长（±0.2s）、画布、`yuv420p`、音轨是否符合预期。
2. 从**成片**抽帧复核（`video-sheet --interval 2`）；当前模型看不到图时，把帧交用户确认。
3. 封面帧：产品清晰、不是虚焦/半开盖的瞬间。
4. 字幕同步且在安全区内；首尾无黑帧、无未裁剪的杂音。
5. 音乐版权来源可追溯（用户提供或已授权）；人物出镜已获同意。
